# Wortschatz 2

Распакуй архив и загрузи его содержимое в корень нового репозитория GitHub. В Settings → Pages выбери Deploy from a branch, ветку main и папку / (root). Открой ссылку GitHub Pages. Для установки открой её в Safari на iPhone или в Chrome на Android и добавь приложение на главный экран.

Первый запуск требует подключения к интернету. После подготовки офлайн-копии приложение открывается с того же адреса без сети.

Прогресс хранится на устройстве в базе wortschatz-v2. Резервные копии второй версии доступны в «Ещё». На Android можно нажать «Поделиться файлом» и выбрать доступное приложение для сохранения.

Новые слова, добавленные в изучение, повторяются через 10 минут, затем после правильных ответов через 2 часа, 1, 3, 7, 14 и 30 дней. После ошибки следующая попытка назначается через 10 минут. После успешной попытки слово закрепляется на одну ступень ниже прежней, минимум на первой.

## Google и синхронизация в 2.16

1. В проекте Firebase `wortschatz-e7547` проверь **Authentication → Sign-in method → Google** и **Authentication → Settings → Authorized domains**. Для текущей публикации в разрешённых доменах должен быть `5kostia.github.io`.
2. Открой **Firestore Database → Rules**. Для базы, выделенной под Wortschatz, опубликуй правила из `firestore.rules`. Если база обслуживает и другие приложения, добавь блок `match /wortschatzAccounts/{uid}/entries/{entry}` внутрь существующего блока `match /databases/{database}/documents`, сохранив правила других коллекций. Широкие разрешения, которые также покрывают `wortschatzAccounts`, нужно сузить, поскольку разрешающие правила складываются. Если базы ещё нет, сначала создай базу **(default)** в production mode.
3. Загрузи в тот же репозиторий `index.html`, `app.js`, `sw.js` и добавь `cloud.js`, `results.js` и `results.css`. Если переходишь с 2.12, `cloud.js` уже есть в репозитории. Файл правил используется в Firebase Console. После публикации открой установленное приложение с интернетом и проверь версию **2.16** внизу «Ещё».
4. На телефоне, где уже есть прогресс, открой **Ещё → Google и синхронизация → Войти через Google**. При первом входе подтверди перенос, если хочешь добавить прогресс и личные карточки с этого устройства. При совпадении карточек сохраняется облачная запись. Дождись статуса **Синхронизировано**.
5. Открой приложение на другом устройстве и выбери тот же Google-аккаунт. Изменения, сделанные офлайн, отправятся после подключения. Если одну карточку обновили на двух устройствах, применяется изменение с более поздней отметкой времени. Настройки оформления и режима учёбы хранятся на каждом устройстве.

Синхронизация использует Firestore. Google нужен для входа. Для первого входа на любом устройстве нужны интернет и возможность открыть окно Google. Ручную копию можно сохранить из меню настроек. Чтобы загрузить старую ручную копию для первого переноса, сделай это до входа.

## Результаты в 2.16

В разделе «Слова» можно смотреть активность за неделю, месяц, сезон или год. Все ненулевые значения подписаны прямо на столбцах. Для читаемости у тонких полосок есть минимальная высота. Нажми на столбец для подробностей, а длинный график можно листать вбок. Таблица «По разделам» раскрывается по нажатию и показывает прогресс по уровням. В графике видны сохранённые даты изучения и повторений, а новые события записываются автоматически. Правила Firestore из 2.12 подходят для 2.16.
